# 1. Two Pointer

The **Two Pointer** pattern is mainly used when we can solve an array/string problem by maintaining two indices and moving them according to certain conditions.

### Common approaches

* Left & Right pointers
* Slow & Fast pointers
* Two pointers from opposite ends
* Two pointers after sorting
* In-place array modification

### Problems Solved

| # | Problem                             | Difficulty | Approach               |
| - | ----------------------------------- | ---------- | ---------------------- |
| 1 | Two Sum II – Input Array Is Sorted  | 🟢 Easy    | Left & Right pointers  |
| 2 | Valid Palindrome                    | 🟢 Easy    | Left & Right pointers  |
| 3 | Remove Duplicates from Sorted Array | 🟢 Easy    | Slow & Fast pointers   |
| 4 | Remove Element                      | 🟢 Easy    | Two pointers           |
| 5 | Move Zeroes                         | 🟢 Easy    | Slow & Fast pointers   |
| 6 | Squares of a Sorted Array           | 🟢 Easy    | Two pointers           |
| 7 | Container With Most Water           | 🟡 Medium  | Left & Right pointers  |
| 8 | 3Sum                                | 🟡 Medium  | Sorting + Two pointers |
| 9 | Trap Rain Water                     | 🔴 Hard    | Two pointers           |

> **Key takeaway:**
> The important part of the Two Pointer pattern is not memorizing a particular solution, but identifying when two indices can reduce unnecessary traversal.

---

## Pattern Recognition

When I see problems involving:

* Sorted arrays
* Finding pairs/triplets
* Palindromes
* Removing duplicates in-place
* Comparing elements from both ends
* Moving elements while maintaining order

I consider whether the **Two Pointer** approach can be applied.
